    28→## 1. API 设计规范
    29→
    30→### 1.1 RESTful 风格
    31→
    32→| 约束 | 说明 |
    33→|------|------|
    34→| 资源命名 | 使用 **名词复数**，如 `/customers`、`/conversations` |
    35→| HTTP 动词 | `GET`(查询)、`POST`(创建)、`PUT`(全量更新)、`PATCH`(部分更新)、`DELETE`(删除) |
    36→| URL 层级 | 资源嵌套不超过 **两层**，如 `/customers/:id/interactions` |
    37→| 动作接口 | 非CRUD操作使用 **动词后缀**，如 `/ai/scripts/generate`、`/customers/:id/ai-analysis` |
    38→| 小写+连字符 | URL 路径使用小写字母，单词间以连字符 `-` 连接 |
    39→
    40→### 1.2 统一响应格式
    41→
    42→**成功响应**:
    43→
    44→```json
    45→{
    46→  "success": true,
    47→  "data": {},
    48→  "message": "操作成功",
    49→  "request_id": "req_7f3a1b2c4d5e"
    50→}
    51→```
    52→
    53→**错误响应**:
    54→
    55→```json
    56→{
    57→  "success": false,
    58→  "error": {
    59→    "code": "VALIDATION_001",
    60→    "message": "参数校验失败：phone 字段格式不正确"
    61→  },
    62→  "request_id": "req_7f3a1b2c4d5e"
    63→}
    64→```
    65→
    66→**分页响应**:
    67→
    68→```json
    69→{
    70→  "success": true,
    71→  "data": {
    72→    "items": [],
    73→    "total": 150,
    74→    "page": 1,
    75→    "page_size": 20,
    76→    "total_pages": 8
    77→  },
    78→  "message": "",
    79→  "request_id": "req_xxx"
    80→}
    81→```
    82→
    83→### 1.3 版本管理
    84→
    85→- 所有接口统一前缀：**`/api/v1/`**
    86→- 版本号采用 **主版本号** 管理，不使用次版本号
    87→- 新版本发布时旧版本至少保留 **3 个月兼容期**
    88→- 版本弃用通过响应头 `X-API-Deprecated: true` + `Sunset: <日期>` 通知
    89→
    90→### 1.4 认证方式
    91→
    92→采用 **JWT Bearer Token** 方式：
    93→
    94→```
    95→Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
    96→```
    97→
    98→| 项目 | 说明 |
    99→|------|------|
   100→| Token 类型 | Access Token (短期) + Refresh Token (长期) |
   101→| Access Token 有效期 | **2 小时** |
   102→| Refresh Token 有效期 | **7 天** |
   103→| Token 存储 | 客户端 localStorage 或 HttpOnly Cookie |
   104→| 多设备策略 | 同一账号最多同时 **3 个设备** 登录 |
   105→| RBAC 角色 | `agent`(代理人)、`supervisor`(主管)、`admin`(管理员) |
   106→
   107→### 1.5 错误码体系
   108→
   109→- 采用 **模块前缀_序号** 格式：`AUTH_001`、`VALIDATION_001`
   110→- HTTP 状态码与业务错误码对应
   111→- 每个错误码附中文描述信息，便于前端展示
   112→
   113→### 1.6 通用查询参数
   114→
   115→**分页参数**:
   116→
   117→| 参数 | 类型 | 默认值 | 说明 |
   118→|------|------|--------|------|
   119→| `page` | int | 1 | 页码，从 1 开始 |
   120→| `page_size` | int | 20 | 每页条数，最大 100 |
   121→
   122→**排序参数**:
   123→
   124→| 参数 | 类型 | 默认值 | 说明 |
   125→|------|------|--------|------|
   126→| `sort_by` | string | `created_at` | 排序字段 |
   127→| `sort_order` | string | `desc` | 排序方向：`asc` / `desc` |
   128→
   129→**搜索参数**:
   130→
   131→| 参数 | 类型 | 说明 |
   132→|------|------|------|
   133→| `keyword` | string | 全文搜索关键词 |
   134→| `filters` | object | 结构化筛选条件（JSON） |
   135→
   136→### 1.7 Rate Limit
   137→
   138→| 接口类型 | 限制 | 说明 |
   139→|----------|------|------|
   140→| 普通查询接口 | 60 次/分钟 | 基于 API Key 或用户 ID |
   141→| AI 接口 (SSE) | 20 次/分钟 | 消耗 AI 算力 |
   142→| 认证接口 | 10 次/分钟 | 防暴力破解 |
   143→| 文件上传 | 5 次/分钟 | 防滥用 |
   144→
   145→- 响应头携带限流信息：
   146→
   147→```
   148→X-RateLimit-Limit: 60
   149→X-RateLimit-Remaining: 45
   150→X-RateLimit-Reset: 1706140800
   151→```
   152→
   153→- 超限返回 HTTP `429` + `RATE_LIMIT_001` 错误码
   154→

   157→## 2. 错误码定义
   158→
   159→### 2.1 错误码总表
   160→
   161→| 错误码 | HTTP 状态码 | 说明 |
   162→|--------|-------------|------|
   163→| `AUTH_001` | 401 | 未认证 — 缺少 Token 或 Token 格式错误 |
   164→| `AUTH_002` | 403 | 权限不足 — 当前角色无权访问该资源 |
   165→| `AUTH_003` | 401 | Token 过期 — Access Token 已失效，请使用 Refresh Token |
   166→| `AUTH_004` | 401 | Refresh Token 无效或已过期 |
   167→| `AUTH_005` | 403 | 账号已被禁用 |
   168→| `VALIDATION_001` | 422 | 参数校验失败 — 请求体或查询参数不合法 |
   169→| `VALIDATION_002` | 422 | 文件格式不支持 |
   170→| `VALIDATION_003` | 413 | 文件大小超限 |
   171→| `NOT_FOUND_001` | 404 | 资源不存在 — 请求的资源 ID 无效或已删除 |
   172→| `AI_001` | 503 | AI 服务不可用 — 大模型服务异常 |
   173→| `AI_002` | 503 | AI 请求超时 — 响应时间超过阈值 |
   174→| `AI_003` | 503 | AI 生成内容异常 — 输出不合规或格式错误 |
   175→| `RAG_001` | 404 | 知识库未找到相关内容 — 检索结果为空 |
   176→| `RAG_002` | 500 | 知识库索引异常 — Embedding 或检索出错 |
   177→| `COMPLIANCE_001` | 200 | 合规检查不通过 — 话术内容触犯合规规则 |
   178→| `COMPLIANCE_002` | 422 | 合规规则不完整 — 缺少必要字段 |
   179→| `RATE_LIMIT_001` | 429 | 请求频率超限 |
   180→| `INTERNAL_001` | 500 | 服务器内部错误 |
   181→| `INTERNAL_002` | 503 | 数据库连接异常 |
   182→| `INTERNAL_003` | 503 | 缓存服务异常 |
   183→| `BUSINESS_001` | 409 | 业务冲突 — 如重复创建、状态不允许该操作 |
   184→| `FILE_001` | 400 | 文件上传失败 |
   185→
   186→### 2.2 校验失败详情格式
   187→
   188→当错误码为 `VALIDATION_001` 时，`error` 对象额外包含 `details` 字段：
   189→
   190→```json
   191→{
   192→  "success": false,
   193→  "error": {
   194→    "code": "VALIDATION_001",
   195→    "message": "参数校验失败",
   196→    "details": [
   197→      {
   198→        "field": "phone",
   199→        "message": "手机号格式不正确",
   200→        "value": "123"
   201→      },
   202→      {
   203→        "field": "customer_name",
   204→        "message": "此字段为必填项"
   205→      }
   206→    ]
   207→  },
   208→  "request_id": "req_xxx"
   209→}
   210→```

   219→POST /api/v1/auth/login

   545→## 5. AI 产品专家 API
   546→
   547→> **权限**: `agent`、`supervisor`
   548→
   549→### 5.1 产品问答对话（SSE）
   550→
   551→```
   552→POST /api/v1/ai/product-qa/chat
   553→```
   554→
   555→**Content-Type**: `application/json`
   556→**Accept**: `text/event-stream`
   557→
   558→**请求体**:
   559→
   560→```json
   561→{
   562→  "question": "百万医疗险和重疾险的区别是什么？",
