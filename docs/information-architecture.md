> **文档状态**：当前有效 · 导航已与 frontend/src/app/routes.tsx（21 条路由）对齐
> 最后校准：2026-08-17


> **版本**: v1.0  
> **更新日期**: 2025-07-12  
> **产品定位**: 面向保险代理人的 AI 销售助手工作台（企业级 AI-Native 产品）  
> **核心声明**: 本产品**不是**聊天软件，不是 ChatGPT 套壳。它是以保险销售工作流为核心、AI 深度嵌入每个业务环节的**专业工作台**。

## 1. 信息架构概述

### 1.1 设计原则

| 原则 | 说明 |
|------|------|
| **工作流导向** | 所有页面围绕保险销售实际工作流设计（拓客→分析→触达→转化→跟进→复盘），不创造无业务价值的交互 |
| **AI Native** | AI 不是独立模块，而是渗透到每个页面的辅助能力。用户不需要"打开 AI"，AI 始终在合适的上下文中出现 |
| **企业级金融科技感** | 视觉与交互体现专业、可靠、高效的企业级产品气质，区别于 C 端消费类 AI 产品 |
| **渐进式智能** | 从信息呈现 → 智能推荐 → 主动建议 → 自动化执行，用户始终掌控节奏 |
| **合规优先** | 所有 AI 输出均经过合规校验，话术与建议符合监管要求 |

### 1.2 产品边界

- ✅ **是**: 保险销售全流程 AI 辅助工作台，包含产品知识查询、客户分析、话术生成、模拟陪练、经验社区、成长体系
- ❌ **不是**: 通用 AI 聊天工具、CRM 系统、保单管理系统、OA 系统
- ⚠️ **集成**: 与企业 CRM、保单系统、合规系统通过 API 集成，不在本产品内重建

### 2.2 布局组件说明

| 区域 | 宽度/高度 | 说明 |
|------|----------|------|
| **顶部栏** | 高度 56px，固定顶部 | 全局操作入口，所有页面共享 |
| **左侧导航栏** | 宽度 220px，可折叠至 64px | 一级导航，支持收起/展开，折叠后仅显示图标 |
| **核心工作区** | 弹性宽度 = 视口 - 左侧栏 - AI面板 | 主内容区域，各页面独立渲染 |
| **AI 辅助面板** | 宽度 360px，默认收起 | 右侧滑出面板，承载上下文相关的 AI 辅助能力 |

### 2.3 顶部栏详细设计

```
┌──────────────────────────────────────────────────────────────┐
│ [安诊保 Logo]  │  [🔍 搜索产品、客户、话术...]  │  [✨ AI助手]  │  [🔔 3]  │  [👤 张三 ▼] │
└──────────────────────────────────────────────────────────────┘
```

| 元素 | 交互说明 |
|------|----------|
| **Logo** | 点击回到工作台首页 |
| **全局搜索** | 支持 Ctrl+K 快捷键唤起；搜索范围覆盖产品知识、客户、话术、社区帖子；搜索结果按类型分组展示 |
| **AI 快捷入口** | 点击唤出全局 AI 对话浮层（非跳转页面），可快速提问；支持拖拽到任意页面使用 |
| **消息** | 显示未读数角标；点击展开消息下拉面板；跳转至消息中心 |
| **用户头像** | 下拉菜单：个人设置、切换团队、管理后台（有权限时）、退出登录 |

**导航交互规则**：
- 当前页面高亮，左侧显示 3px 品牌色指示条
- 悬停时显示背景色变化 + Tooltip（折叠态）
- 二级导航采用页面内 Tab 切换，不嵌套在侧边栏
- 管理后台在侧边栏底部独立分组，点击后左侧导航切换为管理后台导航体系

### 2.5 AI 辅助面板

```
┌───────────────┐
│  AI 上下文辅助  │  ✕
├───────────────┤
│               │
│  [与当前页面   │
│   上下文相关的  │
│   AI 建议/     │
│   分析/摘要]   │
│               │
│               │
├───────────────┤
│ [输入框...] [→]│
└───────────────┘
```

**面板规则**：
- 默认收起，通过页面内触发点（按钮、手势、快捷键 `Ctrl+J`）唤出
- 面板内容与当前页面上下文强关联，非通用聊天
- 可通过拖拽右边缘调整宽度（280px ~ 480px）
- 支持固定/取消固定状态
- 面板内有独立输入框，支持针对当前上下文追问

### 5.4 AI话术页面

**话术生成流程**：
1. **输入阶段**: 选择/输入客户信息 → 选择产品 → 选择场景 → 选择风格
2. **生成阶段**: AI 生成话术（展示 Loading 态：「正在根据客户画像生成个性化话术...」）
3. **审核阶段**: 自动合规检查 → 显示合规结果（通过/警告/不通过）
4. **编辑阶段**: 生成结果可编辑，支持拖拽调序、段落增删
5. **输出阶段**: 复制/导出/保存/直接进入陪练练习

**话术合规检查标识**：
- ✅ 合规通过 — 绿色标识
- ⚠️ 存在风险 — 黄色标识，标注风险点
- ❌ 合规不通过 — 红色标识，需修改后重新检查

### 5.5 AI陪练页面

**陪练状态机**：

```
[场景选择] → [准备中] → [对话进行中] → [结束/超时] → [评分生成中] → [结果展示]
                  ↑                                          │
                  └──────────── 重新开始 ←──────────────────┘
```

**陪练中的 AI 提示系统**：
- 提示默认折叠，点击"获取提示"展开
- 提示不直接给出答案，而是给出方向性引导（如："可以尝试用提问方式了解客户的预算范围"）
- 使用提示会影响最终评分（提示使用次数作为减分参考项）
- 支持语音输入（代理人可通过麦克风说话，AI 语音转文字后继续对话）

### 5.6 AI社区页面

**AI 辅助发帖流程**：
1. 点击「AI 发帖」按钮
2. 输入经验关键词或语音描述
3. AI 生成结构化草稿（标题 + 正文 + 推荐标签）
4. 用户编辑确认后发布
5. AI 自动生成帖子摘要（用于列表预览）

**内容审核流**：
- 用户发帖 → AI 预审核（敏感词/合规）→ 人工审核队列（如有风险）→ 发布
- 社区帖子中提到的产品信息，AI 自动标注关联产品标签

| **对话历史为空** | 欢迎引导 + 推荐问题卡片（3~4 个常见问题快捷入口） |
| **客户列表为空** | 引导文案 + 「导入客户」+ 「手动添加」按钮 |
| **消息中心为空** | 插图 + "暂无新消息" + 说明文案 |
| **陪练记录为空** | 插图 + "还没有陪练记录" + 「开始第一次陪练」按钮 |
| **社区无帖子** | 插图 + "还没有人发帖" + 「成为第一个分享者」按钮 |

### 6.10 Skeleton 态

| 场景 | Skeleton 规格 |
|------|-------------|
| **卡片 Skeleton** | 圆角矩形占位，模拟标题(60%宽) + 正文(3行，随机宽度80%/100%/70%) |
| **表格 Skeleton** | 表头固定 + 3~5 行，每行由等宽矩形组成 |
| **对话 Skeleton** | 用户头像圆 + 1~2 行不等宽矩形 |
| **详情页 Skeleton** | 左侧信息卡 + 右侧大矩形 + 下方 2~3 个卡片占位 |
| **动画** | 从左到右的渐变闪光动画（shimmer），周期 1.5s |

### 7.3 深色模式架构预留

- **CSS 变量体系**: 所有颜色值通过 CSS 自定义属性定义，支持 `data-theme="dark"` 切换
- **语义化 Token**: 使用 `--color-bg-primary`、`--color-text-primary` 等语义化命名，而非直接使用具体色值
- **图片处理**: Logo 等图片资源提供 light/dark 两套，通过 CSS 切换
- **AI 界面适配**: AI 对话气泡、引用卡片等组件需单独调试深色模式对比度
- **MVP 阶段**: 深色模式仅做架构预留，不实现完整切换功能
